# Chizurum Amaugo — Portfolio

A responsive, multi-view portfolio website for CRM, workflow automation and Customer Success.

## Sections
- Home
- Dashboard
- My Projects
- Profile
- Certifications & Learning
- Academic
- Tools

## Publish with GitHub Pages
1. Open the repository's **Settings**.
2. Select **Pages** from the left menu.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/ (root)**, then save.
5. Allow a few minutes for the first deployment.

Expected website address: https://zurumamaugo.github.io/

## Personalise before sharing
- Replace `YOUR_EMAIL@example.com` in `index.html` with the email address you want displayed.
- Add your LinkedIn profile URL and a CV link when ready.
- Add your confirmed academic institution, qualification and dates if you want these shown.
- Review all project descriptions for accuracy before publishing.

BukkiBooks and Dillali are labelled as educational case studies. They are not presented as live client deployments.
